# Deep Research Prompt — Print Production and Fabrication

You are a computational-fabrication engineer, print-production specialist, papercraft designer, nesting/packing algorithm researcher, accessibility designer, and classroom-materials expert.

**Current date:** [insert current date]

Create an implementation dossier titled:

**“Production-Grade Polyhedron Nets: Page Packing, Tabs, Materials, and Accessible Output”**

## Goal

Specify a reliable export pipeline for paper, cardstock, laser cutting, and classroom projection while keeping physical dimensions, folds, labels, and calibration accurate.

## Questions

1. Which SVG, PDF, and print-unit practices preserve true scale across browsers and common print dialogs?
2. How should page size, margins, bleed, printer non-printable areas, and calibration marks be modeled?
3. Which 2D packing/nesting methods best place connected nets or split components across pages?
4. When may a connected net be intentionally segmented, and how should tabs/registration restore assembly?
5. How should glue tabs be generated without collision, ambiguity, or weak attachment?
6. How should fold direction, mountain/valley semantics, edge pairing, face numbering, and QR/project identity be encoded?
7. What kerf, score, thickness, and material parameters matter for cutters?
8. How should color contrast, line patterns, large-print labels, tactile cues, and screen-reader alternatives be designed?
9. What calibration protocol verifies printed scale?
10. What export fixtures and golden-image tests are required?

## Required outputs

- standards and source table;
- print/PDF architecture recommendation;
- page and fabrication schema;
- page-packing and tab-generation algorithms;
- accessibility specification;
- calibration and acceptance test protocol;
- sample page templates;
- staged implementation plan;
- known printer/browser limitations and user-facing guidance.
