# MagnaMath 0.4.0

An interactive geometry laboratory for polyhedra, nets, rigid tree-hinge folding,
printing, and magnetic-tile planning.

## Known limitations

- On 2026-11-10, `npm audit` reported 6 affected packages (2 low, 4 moderate; no high), in development dependencies.
- Continuous collision-free folding paths are unproven; sampled collision checks do not prove them.
- Finite-thickness panel closure and magnetic stability remain unproven.

See [release research](research.md) for audit context and evidence gaps.
